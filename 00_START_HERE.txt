TECHNICAL DETAILS
================================================================================

ACTIVATION FLOW:

1. User Input (Flutter App):
   - NIK: 16-digit identifier (e.g., 3524000000000001)
   - Email: New email address (must not be in use)
   - Phone: New phone number (must not be in use)
   - Password: New password (min 6 chars)

2. API Request:
   POST /auth/activate
   Content-Type: application/json
   {
     "nik": "3524000000000001",
     "email": "user@example.com",
     "phone": "082123456789",
     "password": "password123"
   }

3. Backend Processing:
   a. Find donor by nik (unique lookup)
   b. Validate: sumber_data == "pmi_pusat"
   c. Validate: is_activated == false
   d. Check: email not in use
   e. Check: phone not in use
   f. Update: email = payload.email
   g. Update: no_hp = payload.phone
   h. Update: password_hash = hash(payload.password)
   i. Set: is_activated = true
   j. Commit transaction

4. API Response:
   Status: 200 OK
   {
     "id": 1,
     "nama": "Ahmad Rahayu",
     "email": "user@example.com",
     "no_hp": "082123456789",
     "nik": "3524000000000001",
     "is_activated": true,
     "sumber_data": "pmi_pusat",
     "role": "donor",
     "status_aktif": true
   }

5. Post-Activation:
   - User returns to login screen
   - Login with: new email + new password
   - Receives JWT token
   - Accesses app as active donor

VALIDATION & ERROR HANDLING
================================================================================

VALIDATION RULES:

NIK:
  ✓ Must be exactly 16 digits
  ✓ Must exist in database (donor record)
  ✓ Must be from sumber_data = "pmi_pusat"
  ✓ Must not already be activated
  ✓ Must be unique in database

Email:
  ✓ Must be valid email format
  ✓ Must not already be in use
  ✓ Required field

Phone:
  ✓ Must be 8-20 characters
  ✓ Must not already be in use
  ✓ Required field

Password:
  ✓ Must be at least 6 characters
  ✓ Will be bcrypt hashed
  ✓ Required field

ERROR RESPONSES:

404 Not Found:
  "NIK tidak ditemukan di data terdaftar PMI Lamongan"
  → NIK doesn't exist or typo

409 Conflict:
  "Akun sudah pernah diaktivasi, silakan login"
  → Already activated, use login endpoint

409 Conflict:
  "Email sudah terdaftar di sistem"
  → Email in use by another user

409 Conflict:
  "Nomor HP sudah terdaftar di sistem"
  → Phone in use by another user

400 Bad Request:
  "Akun ini bukan hasil impor PMI Pusat, gunakan /auth/register"
  → Account from manual registration, not PMI import
