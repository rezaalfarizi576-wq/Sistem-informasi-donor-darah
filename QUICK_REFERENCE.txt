WHAT CHANGED
===============================================

Before: Backend expected (email + no_hp) to find donor
After:  Backend expects (nik) to find donor - MORE SECURE & UNIQUE

Backend endpoint /auth/activate now:
  INPUT:  { nik, email, phone, password }
  LOOKUP: Find donor by nik (primary identifier)
  UPDATE: Set email, phone, password_hash
  OUTPUT: Updated user object with is_activated=true

    "phone": "082123456789",

Step 4: Login
  POST http://localhost:8000/auth/login
  Content-Type: application/x-www-form-urlencoded
  
  username=newuser@gmail.com&password=password123

Step 5: Test Flutter App
  - Open Activate Account Screen
  - Input: NIK + Email + Phone + Password
  - Verify: Success & redirect to login

===============================================
ERROR MESSAGES & MEANINGS
===============================================

404 - NIK tidak ditemukan di data terdaftar PMI Lamongan
      => NIK tidak ada di database (typo atau belum diimpor)

409 - Akun sudah pernah diaktivasi, silakan login
      => Akun sudah pernah aktivasi, gunakan login biasa

409 - Email sudah terdaftar di sistem
      => Email yang diinput sudah dipakai user lain

409 - Nomor HP sudah terdaftar di sistem
      => Nomor HP yang diinput sudah dipakai user lain

400 - Akun ini bukan hasil impor PMI Pusat
      => User bukan dari impor (registrasi mandiri)

===============================================
VALIDATION RULES
===============================================

NIK:
  - Must be exactly 16 digits
  - Must exist in database
  - Must be from sumber_data = "pmi_pusat"
  - Must not already be activated

Email:
  - Must be valid email format
  - Must not already be in use

Phone:
  - Must be 8-20 characters
  - Must not already be in use

Password:
  - Must be at least 6 characters
  - Will be hashed before storage

===============================================
DATABASE REQUIREMENTS
===============================================

Table: users
Columns needed:
  - id (BigInteger, PK)
  - nik (String 16, UNIQUE, INDEX) ← NEW
  - email (String 150, UNIQUE)
  - no_hp (String 20, UNIQUE)
  - password_hash (String 255)
  - sumber_data (String 20)
  - is_activated (Boolean)
  - All other existing columns

===============================================
TROUBLESHOOTING
===============================================

Problem: NIK not found
Solution: Run import script: python scripts/import_pmi_dataset.py

Problem: Database error (column nik doesn't exist)
Solution: Ensure database schema updated with nik column

Problem: 409 Conflict on email/phone
Solution: Use different email/phone or different NIK

Problem: Flutter doesn't send phone parameter
Solution: Check auth_repository.dart - phone should be required

Problem: Backend receives wrong payload
Solution: Check Content-Type header = application/json
