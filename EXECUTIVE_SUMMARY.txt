================================================================================
IMPLEMENTATION FLOW
================================================================================

ACTIVATION PROCESS:

User (Flutter App)
  ↓
  Input: NIK (16 digits) + Email + Phone + Password
  ↓
POST /auth/activate
  {
    "nik": "3524000000000001",
    "email": "user@gmail.com",
    "phone": "082123456789",
    "password": "password123"
  }
  ↓
Backend Processing:
  1. Lookup donor by NIK
  2. Verify sumber_data == "pmi_pusat"
  3. Verify is_activated == false
  4. Check email not in use
  5. Check phone not in use
  6. Update: email, no_hp, password_hash
  7. Set: is_activated = true
  8. Commit to database
  ↓
Response: 200 OK
  {
    "id": 1,
    "nama": "Ahmad Rahayu",
    "email": "user@gmail.com",
    "no_hp": "082123456789",
    "is_activated": true,
    "sumber_data": "pmi_pusat"
  }
  ↓
Flutter App
  Show: "Akun berhasil diaktivasi! Silakan login."
  Navigate: to Login Screen
  ↓
User Login
  POST /auth/login
  email: user@gmail.com
  password: password123
  ↓
Success: JWT Token + Access to app as Donor
