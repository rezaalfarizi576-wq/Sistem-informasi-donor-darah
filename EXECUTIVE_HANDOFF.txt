TECHNICAL IMPLEMENTATION
================================================================================

Account Activation Flow:

1. USER INPUT (Flutter App)
   NIK (16 digits) + Email + Phone + Password

2. API CALL
   POST /auth/activate
   {
     "nik": "3524000000000001",
     "email": "donor@example.com",
     "phone": "082123456789",
     "password": "password123"
   }

3. BACKEND PROCESSING
   - Lookup donor by NIK (primary identifier)
   - Validate sumber_data == "pmi_pusat"
   - Validate is_activated == false
   - Check email not in use
   - Check phone not in use
   - Update: email, no_hp, password_hash
   - Set: is_activated = true
   - Commit transaction

4. RESPONSE
   200 OK
   {
     "id": 1,
     "nama": "Ahmad Rahayu",
     "email": "donor@example.com",
     "no_hp": "082123456789",
     "is_activated": true
   }

5. POST-ACTIVATION
   - User navigates to login
   - Login with new email and password
   - Receives JWT token
   - Accesses app as active donor

VALIDATION RULES:
  NIK:      16 digits, must exist, must be from PMI import, must not be activated
  Email:    Valid format, must not be in use
  Phone:    8-20 chars, must not be in use
  Password: Min 6 chars, will be bcrypt hashed

  404: "NIK tidak ditemukan di data terdaftar PMI Lamongan"

  400: "Akun ini bukan hasil impor PMI Pusat, gunakan /auth/register"
