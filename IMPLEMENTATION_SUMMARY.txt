================================================================================
FLOW ALUR AKTIVASI AKUN DONOR
================================================================================

1. USER (Flutter App)
   Input: NIK + Email Baru + Phone Baru + Password

2. FRONTEND
   POST /auth/activate
   {
     "nik": "3524000000000001",
     "email": "user.baru@gmail.com",
     "phone": "082123456789",
     "password": "password123"
   }

3. BACKEND
   - Cari user by nik
   - Validasi: sumber_data == "pmi_pusat"
   - Validasi: is_activated == False
   - Validasi email & phone tidak duplikat
   - Update: email, no_hp, password_hash
   - Set: is_activated = True

4. RESPONSE
   Status 200 OK
   {
     "id": 1,
     "nama": "Ahmad Rahayu",
     "email": "user.baru@gmail.com",
     "no_hp": "082123456789",
     "is_activated": true
   }

5. USER
   - Login dengan email & password baru
   - Dapatkan JWT token
   - Akses aplikasi sebagai donor
